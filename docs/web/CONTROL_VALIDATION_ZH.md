# 网页真实控制与保持链路验证

**实测更新：阶段A已真实执行并通过**，四次接口操作完成接管/保持/释放，最终Input=None、夹爪占用已释放；未发送新运动目标。见[阶段A结果](STAGE_A_RESULT_ZH.md)。下文部署验证部分保留上线时的历史状态。

2026-10-14，已接入8096页面。推理功能仍不向机器人发送预测；新增面板只在用户明确确认并点击测试按钮后调用真实接口。

## 当前支持

1. **只读检查**：读取Apex状态与采集进程的真实关节/夹爪位置、速度。检查新鲜度、静止、原目标、占用和回放状态，不改变设备。
2. **接管 → 保持 → 释放**：重新检查稳定性；切Input为None；继承现有夹爪目标接管；观察真实位置/速度；发送hold并核对held；释放本次会话。不会发送target、TCP、关节或模型动作。
3. **租约超时保持**：同样在静止接管后，不续心跳，观察驱动进入“心跳超时held”；随后确认hold并释放。只证明静止情况下的租约和保持状态，不证明运动中停止。
4. **中止并请求保持**：中止当前流程，若确认仍持有本会话则请求hold并保留占用；需要用户检查后明确释放。未知会话或驱动重启时不操作别人的占用。

两种真实测试结束后 **Input保持None，不自动恢复Teleop**。Robot Mode不改变。恢复遥操应在Apex控制台明确操作。

“有限运动 / 运动中停止验证”按钮禁用。模型运动执行、制动距离、急停和真实动力学尚未验收，不能把接口回执或停止发布消息描述成运动已经停止。

## 页面操作

- 找到“真实控制与保持链路验证”面板。
- 点击“检查当前静止条件”，查看原因和速度。若某一项超限，先处理真实状态，不修改门槛掩盖问题。
- 确认工作区无人接触、设备静止、物理急停可用，并允许Input切None后，勾选确认框。
- 点击一种测试，浏览器再次明确展示会发生的操作；确认后才启动。
- 观察步骤日志、接管状态、接口操作次数和真实反馈。需要时点击“中止并请求保持”。
- 若状态为HELD_REVIEW或UNCERTAIN，先检查设备，之后由本浏览器会话明确释放；未知所有权时请在Apex检查。
- 下载报告，区分接口确认与物理停止结论。

页面加载、刷新、只读检查和影子推理都不会自动触发真实测试。真实验证与影子推理互斥；同一时刻只有一个验证持有者，其他浏览器只能查看。

## 实际检查条件

- 机器人ready、无错误、状态年龄≤0.5秒；Robot Mode仅接受当前Position或Impedance，不主动修改。
- Input必须原为None/Teleop；不会中断Planner/Playback，运行或暂停回放均拒绝。
- 关节/电机原始速度与位置年龄≤0.5秒；关节速度绝对值≤0.02 rad/s，网页电机速度检查放宽为绝对值≤0.03 rad/s；原驱动claim瞬间仍检查≤0.02 rad/s，未改驱动。
- 原夹爪目标合法，实际位置距原目标≤0.05 rad；允许健康容差内的负实际反馈，不用actual作为claim目标。
- 夹爪底层反馈年龄加状态年龄≤0.3秒。
- 验证过程中相对初始关节偏移>0.005 rad、夹爪位置变化>0.01 rad、目标改变或模式/所有权改变即中止。

2026-10-14按用户要求，仅把网页侧夹爪瞬时速度门槛从0.02放宽到0.03 rad/s，允许已观察到的约0.022 rad/s波动。只读检查和启动后的监控使用同一配置；关节、目标偏差、位置漂移和新鲜度规则不变，历史失败记录不重写。

这些阈值用于“不发新目标的静止测试”，不是运行模型动作的速度/工作空间安全许可。夹爪速度可能有量化抖动；只读检查一瞬间通过不保证启动后仍通过，后端会重复检查。

## 实现边界和故障处理

- Apex客户端地址固定为本机8080；仅允许set_input=0以及claim/hold/release。没有任意URL、任意动作或目标字段转发接口。
- 真实入口使用原有签名Cookie、同源和CSRF校验，确认框和请求类型由服务端严格验证。
- 接管前持久化会话意图，所有外部POST计数写入报告；超时不自动重发claim。
- claim回执丢失后先查状态，只有boot/session确实属于本验证才请求hold；不会释放其他会话。
- hold未确认时标记UNCERTAIN，不伪称已停止，也不自动释放。
- 浏览器失联、主动中止、服务器关闭会进入本会话保持处理。服务重启把活动记录标记INTERRUPTED_REVIEW，不自动续接或启动动作。
- 报告保存于`data/control-validation/`，包含时间、阶段、反馈和结果。页面与下载隐藏驱动会话标识。
- 本流程不保证下游通信/硬件故障时软件hold能抵达；真实运动仍需要独立硬件急停和进一步验证。
