# 推理页面 HOME 双臂复位（2026-10-15）

8096 推理页面已增加“HOME · 双臂复位”按钮，位于四个推理/闭环按钮下方，整行对齐。点击后自动检查启动条件、切换到Planner、调用与8081原控制台相同的Apex `POST /api/v1/robot/reset`，等待原生HOME根据实际关节反馈确认到位，然后切回Input=None，方便继续推理。

本功能复位双臂，不是故障清除、夹爪校准或重置模型。保持原Robot Mode；只接受Position/Impedance和None/Planner来源，不从遥操作/回放来源抢占。原生HOME仍使用在用规划器的HOME关节参数及速度、加速度配置。

## 操作

1. 如果真机闭环正在运行，先点击“停止真机闭环”，等待停止确认。仅推理或控制验证也须先结束。
2. 点击“HOME · 双臂复位”。页面显示准备/复位中/到位结果，复位期间不能再启动推理或另一个HOME。
3. 页面显示“HOME复位完成，Input=None，可继续推理”后，可重新点击“开始连续”或“仅单次推理”。页面加载和刷新不会自动发送HOME。

这里额外完成Planner来源切换和结束时切回None；原8081控制台的HOME成功后保持Planner。动作规划、原生到位判定和原生失败停止流程仍来自同一个Apex后端。未新增SDK控制连接或关节目标发布器。

## 异常与记录

原生HOME的HTTP调用可能持续约90秒，网页异步等待并显示状态，不占住API事件循环。重复请求ID返回已有操作，不重复发送复位。反馈过期、仍在运动、已有占用或回放时拒绝启动。

失败后核对原生HOME和输入来源；确认操作结束后切回None。无法确认的情况显示“状态待确认”，不将请求超时当作机器人停止。网页重启也不会重放HOME；可点击“核对HOME状态”进行只读核对。复位期间的实际运动停止沿用原控制台/机器人原生路径，本次没有增加新的HOME中途取消接口；“停止真机闭环”不作为HOME取消按钮。

状态与请求记录保存在 `data/home/current.json` 和同目录各运行ID文件。请求沿用当前网页会话、同源和CSRF校验。
