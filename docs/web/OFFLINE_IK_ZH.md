# 离线 IK 与轨迹检查

日期：2026-10-14。功能已接入实时影子网页。本文描述软件诊断，不表示机械臂执行或真实任务已验收。

## 已实现

每份新预测绑定原始观察中的14个实际关节角，调用独立离线进程检查50步TCP/夹爪目标。网页增加关节骨架、左右关节角表、位置/旋转误差、最小碰撞距离、限位余量、跳变与拒绝原因。使用原有步滑块切换预测步；可以查看最近已检查预测，再点击“跟随最新预测”恢复自动更新。

关节来源为 `/tj/joint_states`，按 `Joint1_L…Joint7_L、Joint1_R…Joint7_R` 明确重排，拒绝缺失、重复名称和非有限值。关节历史按图像源时间选择最近样本，记录原始采样/接收时间；模型输入仍是原来的26维，关节角作为诊断元数据额外保存。

历史记录没有关节快照时显示不可检查，不使用当前关节角或预测动作冒充实际起点。检查以观察时刻的数据为准，不将这些旧关节角当作实际执行时的状态。

## 求解与边界

复用已安装的 `QpControllerCore` 静态库、完整 `matrix/m6_696.xml`、`left_tool/right_tool` 和在用任务配置。位置为米、姿态为固定轴xyz外旋弧度，转换后直接使用绝对TCP目标，不叠加当前位置或手动修改7毫米工具偏差。

求解进程只使用标准输入输出协议，没有ROS节点、硬件SDK连接或控制发布器。模型、网格、任务、碰撞对、速度限制、核心库及工作程序的SHA256写入每份检查结果。

系统Python中的DAQP 0.8.7与现有核心库的设置结构布局不同，因此没有混用。离线构建固定DAQP 0.7.2，并以编译检查和求解测试核验兼容性。这里复用了在用核心算法和配置，但不宣称与在用控制器的全部二进制依赖、实际伺服行为逐位等价。

`config/ik.json` 记录完整门槛，包括：

| 项目 | 当前值/范围 |
|---|---|
| 求解内部步长 | 0.002 s，与在用QP的500 Hz对应 |
| 目标位置/旋转误差 | 1 mm / 0.01 rad |
| 起点FK与TCP反馈一致性 | 10 mm / 0.05 rad；是诊断门槛，不是物理标定精度 |
| 关节限位 | 完整模型中的上下限 |
| 速度限制 | 在用 `m6_696/velocity_limits.json` |
| 关节单步变化 | 0.35 rad |
| 动作间隔 | 1/30 s；起点至首目标也假定有一个间隔 |
| 碰撞间距 | 已配置几何体之间至少5 mm |
| 区间采样 | 最大关节变化每0.02 rad取一个样本，最多32个；超出则拒绝，不能当作已检查 |
| 求解预算 | 每步最多400次迭代，每份最多3秒；进程响应另有5秒超时 |

内部求解迭代不是动作执行时间。速度检查使用相邻关节解与上述动作间隔，不能据此证明实际控制链能按该时序跟踪。未做驱动动态、加速度、接触力或实机停止行为验收。

当前碰撞配置只有8对：左右 `Link4/Link5` 与基座，以及这两组连杆之间。没有覆盖夹爪、桌面、工件和其他未列出的几何对。区间离散采样也不是连续碰撞检测证明。网页显著标注该范围，即使全部检查通过，`execution_verified` 仍为false。

“未收敛”只说明本求解器在当前目标、初值、软目标和预算下未找到满足阈值的解，不是数学不可达证明。

## 异步运行与记录

推理与离线检查独立运行。离线侧最多一个在途任务和一个最新待检查任务；新的待检查任务替代旧任务时记录 `superseded`。原预测和图片保持可追溯。

结果按预测ID写回数据库。停止或新会话产生版本变化后，旧检查可以作为历史记录保存，但不会覆盖新预测。服务重启会将未完成的pending记录标为interrupted。进程故障或超时会显示不可用，并保持影子推理服务可用；不会自动获取机器人控制权。

旧的API记录中 `offline_ik` 可能是字符串 `unavailable`；新记录为结构化对象。导出ZIP中的预测JSON包含关节轨迹、阈值、残差、碰撞对和失败原因，输入NPZ包含对应关节快照。

## 验证结果

- 20项Web/数据契约/离线求解测试通过；覆盖起点过期、名称重排、缺失关节、FK不一致、限位、速度、夹爪范围、配置碰撞、无解目标、队列替换和迟到结果隔离。
- 使用实际反馈及32组随机配置，共33组关节角，将独立Pinocchio工作程序与训练使用的MuJoCo完整模型交叉验证。左右工具点最大位置差约 `1.34e-15 m`，最大旋转差约 `2.38e-15 rad`。这是软件模型一致性验证，不是实体TCP标定。
- 真实网页检查通过：桌面/手机布局、50步切换、投影切换、异步结果更新，无页面JavaScript异常。
- 连续12次真实推理，共600步，都完成了离线检查；每份检查最长约52毫秒。模型RPC稳态P95约1.31秒。
- **这12份真实预测均未通过动作检查**：均存在夹爪目标越界和部分节点未收敛。没有裁剪或放宽阈值来制造通过结果，也没有执行这些预测。

证据位于 `artifacts/offline-ik-20261014/`：`fk-crosscheck.json`、`browser-report.json`、`continuous-model.json`、`continuous-ik.json` 及截图。

## 构建与使用

```bash
cd /home/user/forcevla-web
bash scripts/build_ik.sh
systemctl --user restart forcevla-web.service
```

网页地址保持端口8096。刷新旧页面后，进行单次或连续推理即可自动检查。`config/local.json` 的 `offline_ik.enabled` 可关闭这一功能；关闭后仍保留原来的影子推理。

```bash
env -u PYTHONPATH -u VIRTUAL_ENV PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/pytest -q tests/test_offline_ik.py tests/test_shadow.py
/opt/kernelmind/venv/bin/python scripts/verify_ik_fk.py
node tests/browser_ik.mjs
```

最后两个实时测试入口 `tests/browser_ik.mjs`、`scripts/verify_live_ik.py` 会调用真实模型服务，但不会发送机械臂动作。原先V1的30分钟报告不自动覆盖新功能；本次新增检查的真实连续验证为12次预测。
