# 推理页面 Restart Gripper（2026-10-15）

**历史版本说明：推理页面此按钮已改为显式发送初始位置目标0，当前行为见 [夹爪初始目标说明](GRIPPER_INITIAL_TARGET_ZH.md)。**

8096页面已增加“Restart Gripper”，与HOME位于同一行。它调用与8081原控制台相同的 `POST /api/v1/gripper/restart`，经Apex后端触发 `/control/reset_grippers`。

安装驱动的实际动作是：先失能两侧夹爪电机，等待约0.1秒，再使能两侧电机。该操作不重新扫描标定范围，不自动把目标归零，不复位双臂，也不改变机械臂控制模式或输入来源。

## 使用

闭环、HOME、其他推理或控制验证运行时，先结束当前操作。待Input=None、双臂静止且夹爪占用释放后点击Restart Gripper。页面显示正在重启/核对反馈；接口确认成功并收到两侧使能、健康的新反馈后显示完成。

按钮不会要求夹爪实际位置达到现有目标；已删除的到位等待逻辑没有恢复。完成表示电机重启及新反馈确认，不表示夹爪目标位置偏差已经消失。重启后目标仍按原驱动保留，如果此前目标1.0、实际约0.79144的差异依旧存在，启动接管仍可能被驱动拒绝，需继续检查该差异。

通信超时或反馈未确认时不自动重发；页面显示“核对夹爪状态”，再次点击只读取当前反馈。页面加载、刷新、网页服务重启均不会自动重启电机，也不会自动恢复旧闭环。
