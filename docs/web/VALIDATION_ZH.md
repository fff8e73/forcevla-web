# V1 实现与验证记录

日期：2026-10-14。

## 已交付

- 独立Python Web服务、ROS只读采集进程和本地静态页面。
- 四路H.264解码/输入预处理，TCP、力觉、夹爪组成26维状态及源时间检查。
- 单次/连续影子推理、同一RPC请求ID追踪、单在途调度、停止后迟到结果丢弃。

- Cookie/CSRF/Origin校验、会话持有者权限、断连自动停调度、SQLite持久化、ZIP导出。
- 用户服务 `forcevla-web.service` 已启用；启动不自动推理。模型服务及原机器人控制链未改动。

## 稳定性补充验收

正式30分钟复测通过：1357次推理、输入有效率100%、RPC P95 1.266秒、RSS峰值385.9 MiB。视频传输、进程内存保留和网页重连问题已修复；失败基线及完整复测记录均保留，门槛未放宽。详见 [稳定性修复与验收](STABILITY_REPORT_ZH.md)。

训练转换代码的同输入四路输出逐像素一致，预览/原生录制帧的几何与颜色对照通过。额外验证了真实RPC超时不重试、采集暂停与恢复、持有者断连停止、模拟服务强制重启后的自动重连，以及真实服务中的多浏览器权限。

## 尚未通过的验收项

- 现场物理相机映射与曝光同步；预览/录制编码不逐像素相同，软件对照不替代实际任务验证。
- 离线同模型IK、关节可达性、碰撞检查、物理TCP/力觉标定及任务成功率。

这些限制在页面或使用说明中标注。当前交付支持基础影子诊断，不宣称原控制计划P2全部通过，也不开放实机执行。
